Four styles to choose from

Each section shows the same screens in a different style: the desktop three-pane view (Inbox, lists, filters, nested tags), the Android home-screen widget showing a filter, and the week calendar with Google events (grey) next to timed tasks (tag colour). Use the Light/Dark switch on each one. All task data is made-up sample content.

Style A

Quiet

Calm and neutral, close to TickTick and Things. Lots of whitespace, round checkboxes coloured by priority, and tags as small coloured dots.

Good for
  • Long sessions without visual noise
  • Feels familiar coming from TickTick
  • Works on Mac and Android
Trade-offs
  • The least distinctive of the four
  • Tags are subtle, so they're less "first-class" at a glance
Style B

Tiling

Keyboard-first and dense, at home next to Hyprland, waybar and a terminal. Monospace type, square corners, #tags as coloured text and a Catppuccin-like palette.

Good for
  • Most tasks per screen
  • Matches a riced Linux desktop
  • Tags read like the CLI (tt ls -t health)
Trade-offs
  • Monospace on a phone feels busy
  • Out of place among macOS apps
Style C

Soft

Friendly and tactile. Each task is its own rounded card, and tags are filled pastel pills that stand out. Bold headings and a teal accent.

Good for
  • Tags are the most visible of all four
  • Easy to tap on the phone and widget
  • Pleasant on touch screens
Trade-offs
  • Fewer tasks fit on screen
  • Cards add visual weight with 400+ tasks
Style D

Material

Android-native Material 3 (Material You): tonal surfaces, pill-shaped navigation, outlined tag chips and big rounded widgets. On Android it could follow the wallpaper's colours.

Good for
  • Phone and widget feel native to Android
  • Flutter has Material 3 built in, so it's the least design work
  • Dynamic wallpaper colours on Android 12+
Trade-offs
  • Looks "Android" on the Mac and Linux desktop
  • Generic unless customised

How to choose

Pick one, or mix them, for example "Quiet layout with Soft tag pills" or "Tiling on desktop, Material on Android". Colours, density and the tag treatment are each easy to swap. The layout (three panes, a widget with a header and a + button, a week grid) stays the same whichever style you pick.
