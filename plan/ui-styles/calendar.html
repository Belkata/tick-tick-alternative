Calendar mockup

M5a slice 2, in the Soft style. Static sample data for the week of 23 November 2026; "now" is Wednesday 11:40.

What to look at

  • Blocks are tinted with the first coloured tag (else the list, else teal) and have a coloured edge. Short blocks collapse to one line.
  • Completed blocks are faded, with no strike-through. Future repeat occurrences carry ↻ and can't be dragged; only the current one has a resize grip.
  • Overlaps sit side by side (Wednesday 11:00). The selected block has a teal outline and its detail opens on the right, replacing the Unscheduled panel.
  • Dragging in: "Plan the trip" is being dragged from Unscheduled; the dashed box shows where it lands (30 min).
  • Month shows every repeat occurrence too, so a daily task (Stretch) takes a line in every cell. Worth deciding whether Month should hide daily repeats.
  • Room for the grid: in calendar mode the sidebar folds to an icon rail (» brings it back), so seven days fit next to the Unscheduled panel on a laptop screen.
  • Phone: Day view with a week strip (swipe between days); Unscheduled is a bottom drawer. The second phone shows a long-press drag out of the open drawer.
